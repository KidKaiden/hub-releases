Hub 0.14.0

New: Lock a chat from the chat itself: the lock at the top of each chat. Messages > Settings keeps the default for every chat; Search everything finds settings: type password, theme, notifications or recovery key and go straight there. Improved: Settings is now a few doors, each saying how it stands: You, Look, This device, AI and tools, Admin, Setup guides, Updates and backup. Everything inside is grouped, and every group says what it's for; One home for each thing: your account, two-step sign-in and devices in You; the look only in Look (apps link there); the server's update, safety, keys, backups and recovery key all in Admin; Every app's settings follow the same order: how it works, alerts, privacy, your data, look, help

Installed Hubs update by themselves (Hub > Updates). New install: Windows, run the setup file; Android, open the APK (allow installs from your browser when asked).
